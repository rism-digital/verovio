# Test faces

`Tinos-Regular.ttf` is the static source face of the bundled
`data/fonts/Tinos-Regular.woff2` (see `data/fonts/README.md`). The WOFF1 and
WOFF2 files are deterministic encodings of it, produced with fontTools for the
decoder tests. They are fixtures only.

The Bravura tests use the source font `fonts/Bravura/Bravura.otf`.
